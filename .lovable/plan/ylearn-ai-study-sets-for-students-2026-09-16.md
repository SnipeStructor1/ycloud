# yLearn — AI study sets for students

A dark-mode-first study app where every flashcard set is generated by AI from a topic, pasted text, or an uploaded photo/PDF. Students keep their own library, share sets publicly, and study with flashcards, quizzes, and an AI tutor.

## Accounts
- Sign up and log in with email + password, plus Google sign-in.
- Each account has a profile dashboard: sets they created, sets saved from the community, total cards learned, and current day streak.
- Every set belongs to its owner; private sets are only readable by that owner.

## Creating a set (AI only)
No manual card entry anywhere in the app. Three ways in:
- Type a topic ("French Unit 3 Vocab", "Human Digestive System")
- Paste raw text or notes
- Upload an image or PDF (textbook page, summary sheet, handwritten notes)

The AI returns a titled set with a subject tag, 10–20 flashcards (term/question on the front, clear explanation on the back), and a handful of summary bullets. A preview screen lets the student accept or regenerate before saving.

## Sharing
- New sets are Public by default.
- A visibility switch on the set page flips between Public and Private.
- An Explore page lists public sets with search and subject filters; any set can be saved/cloned into your own library.

## Studying
- **Flashcards**: full-screen flip cards, swipe on mobile, arrow/space keys on desktop, and Easy / Medium / Hard rating that schedules each card for review (simple spaced repetition).
- **Quiz**: AI-built multiple-choice and fill-in-the-blank questions from the set, scored at the end.
- **AI Tutor**: a chat drawer open on any study page, with one-tap "Explain this simpler" for the current card plus free-form follow-up questions.

## Look and feel
Dark-mode first, high-contrast typography, one vibrant accent colour, generous spacing, works down to small phone screens. I'll propose a few visual directions before building the interface.

## Mock content
The app ships seeded with realistic public sets — Biology: Human Organs, French Vocabulary, World History: Cold War, Chemistry: Periodic Trends and others — so Explore and study modes are usable from the first visit.

## Technical notes
- Lovable Cloud for accounts, database, file storage (uploads), and server logic.
- Tables: `profiles`, `study_sets`, `cards`, `saved_sets`, `card_reviews` (SRS state + streak source), `tutor_messages`. Row-level security on all of them: owner-only writes, public-read only where `visibility = 'public'`.
- AI generation, quiz generation, and tutor chat run through Lovable AI on server functions; uploads are parsed server-side (vision model for images/PDFs). Streaming responses for the tutor chat.
- Routes: `/` landing, `/auth`, `/dashboard`, `/create`, `/explore`, `/set/:id`, `/set/:id/study`, `/set/:id/quiz`.
- Seed data inserted via migration so it exists on first load.
